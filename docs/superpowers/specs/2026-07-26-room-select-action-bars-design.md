# Room Select 主操作横条像素锚定设计

状态：用户已确认设计方向，等待规格复核。

## 目标

先把图 9 右侧的“创建同盟”和“加入同盟”两条主操作横条做到局部完全对齐，再把它们作为后续装饰物定位的坐标锚点。本轮不要求创建区和加入区的其余装饰完成视觉验收，但它们不得遮挡横条或拦截横条点击。

本轮不改变创建房间、发现房间、房间号预填、加入房间或 LAN 协议行为。

## 测量依据

参考图为 `docs/references/ui/battle_hud/图9.png`，尺寸为 `2102×1149`。

两张横条贴图均为 `537×105`：

- `room_select_create_btn_bg_down.png`
- `room_select_join_btn_bg_down.png`

贴图有效色块测量：

| 横条 | 贴图有效色块 | 图 9 有效色块 | 结果 |
| --- | ---: | ---: | --- |
| 创建同盟 | `521×90` | `740×89` | 水平约放大 `740 / 521 = 1.4203`，垂直约保持原尺寸 |
| 加入同盟 | `521×91` | `740×93` | 水平约放大 `740 / 521 = 1.4203`，垂直约保持原尺寸 |

图 9 中两条横条的水平有效色块范围相同，均约为 `x=1268..2007`。创建横条的垂直有效色块约为 `y=489..577`，加入横条约为 `y=938..1030`。

因此，参考实现有意把原始横条贴图横向拉伸；保持贴图原始 `537:105` 比例不能复刻图 9。

## 坐标与缩放决策

不对整个局部 UI 分别按 X、Y 非等比归一化。图 9 的宽高比 `1.8294` 与 16:9 的差异约为 `2.9%`，创建区和加入区内部坐标应作为一个参考局部坐标系保留。

采用以下转换：

1. 以参考图高度映射到 1080：统一缩放 `s = 1080 / 1149 = 0.93995`。
2. 参考图缩放后的宽度约为 `1975.8`，在 1920 宽画布上采用约 `-27.9px` 的整体水平偏移作为初始值。
3. 两条横条在参考坐标中的完整 Rect 初始估算为 `763×105`；换算到 1920×1080 后约为 `717×99`。
4. 两条横条使用相同 X、相同宽度和相同高度，仅 Y 不同。

1920×1080 的首轮目标 Rect（屏幕左上为原点）为：

| 横条 | X | Y | Width | Height |
| --- | ---: | ---: | ---: | ---: |
| 创建同盟 | `1154` | `453` | `717` | `99` |
| 加入同盟 | `1154` | `876` | `717` | `99` |

对应 Unity 左下原点的初始 Bottom 值为：创建 `528`，加入 `105`。这些值是由测量得到的首轮锚点；第一次局部截图校准允许对两个区域分别做最多 `4px` 的整体平移，但不得改变二者共同的宽高。校准后的整数坐标立即写入布局测试，最终实际 Rect 与校准目标的误差不得超过 `2px`。

## 组件设计

创建区和加入区分别保留独立容器。横条是各自容器的主锚点，横条背景 `Image.preserveAspect` 必须关闭，Rect 直接使用测得的宽高。

每条横条内部包含：

- 对应的 `room_select_*_btn_bg_down` 背景；
- 现有、已登记来源的操作图标；
- Unity 文本“创建同盟”或“加入同盟”；
- 与背景完全一致的点击 Rect。

图标和文字使用横条局部坐标，不跟随外部装饰重新计算。文字和图标必须位于横条内容安全区内，并在横条之上渲染。

所有区域允许多张素材重叠。除横条自身的图标和文字外，本轮其他装饰必须位于横条背景之后，不得遮挡横条主体，不得拦截其 raycast。透明命中层仍可保留，但不得扩展或替换横条的主点击范围。

## 本轮明确不做

- 不精调创建区的十字、Logo、说明文字、装饰线位置；
- 不精调加入区的方块、密钥格、三角形、邀约条和说明文字位置；
- 不以整张 Home 的总差异率作为两条横条是否通过的唯一依据；
- 不修改 Room 页面、网络或房间行为。

`room_select_create_left_line` 的复制与 180°旋转属于下一轮装饰定位。下一轮以创建横条为锚点放置左线，并复制同一 Sprite 旋转 `180°`构成右侧；加入区的装饰允许通过层叠复刻图 9。

## 验收与验证

### 自动布局断言

- 两条横条 Rect 在 1920×1080 下使用相同 X、Width、Height；
- 目标宽高为约 `717×99`，位置以测量 Rect 为基准，误差不超过 `2px`；
- 背景允许非等比水平拉伸，不再断言背景 Rect 与 Sprite 原始宽高比相同；
- 图标和文字是对应按钮的子节点；
- 创建和加入事件、六位房间号预填以及加入可用性测试继续通过；
- 其他装饰不得覆盖横条的渲染层或拦截按钮点击。

### 局部视觉证据

真实 1920×1080 Player 截图额外生成两个局部区域：

- `home-create-action`：只比较创建横条及其图标、文字；
- `home-join-action`：只比较加入横条及其图标、文字。

报告分别列出参考 Rect、实际 Rect、尺寸偏差、位置偏差和局部差异，不以左侧身份区或其他暂未精调装饰影响两条横条的结果。
