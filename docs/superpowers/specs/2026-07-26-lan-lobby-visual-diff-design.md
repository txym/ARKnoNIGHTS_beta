# LAN 房间 UI 自动差异报告设计

**状态：已由用户确认，待实现计划。**

## 目标

为 LAN 房间大厅生成非阻断式视觉差异报告，使用参考图 `图9.png`（主页）和 `图10.png`（房间）核查实际 Windows Player 截图，并逐项报告实际渲染的 UI 素材来源。

视觉差异用于人工审阅，不以像素偏差阻断验收。输入不完整、未映射素材、非法输出目录或参考图不唯一则属于工具错误，必须返回非零并且不得写出部分报告。

## 输入与边界

- 实际截图必须由现有 `LanLobbyCaptureSuite` 生成：`home`、`discovered-prefill`、`room-host`、`room-ready`、`room-full`，并携带 `manifest.json`。
- 引用目录由脚本参数显式提供；默认值为调用工作树中的 `docs/references/ui/battle_hud`。脚本不把参考图复制到 `Assets/`，也不将其作为游戏资源。
- 参考图必须精确且唯一地包含 `图9.png` 和 `图10.png`；找不到或多于一个即失败。实现工作树无法携带主工作树后加入的参考图时，调用者应传入主工作树的参考目录。
- 所有生成物只允许写入已验证项目根下的 `Temp/` 或 `Artifacts/`。禁止写入 `Assets/`、项目根、外部路径和路径前缀逃逸。

## 比对规则

所有截图以 1920×1080 为基准；尺寸不同的输入在报告中标为不兼容，不进行静默拉伸。

### 图 9：主页

- 核查：全屏背景、创建房间卡、加入房间卡、房间发现与六位房间号预填、左侧身份区域。
- 屏蔽：左上与左下参考区域，以及左侧雷达的大小/形状差异。

### 图 10：房间

- 核查：全屏背景、四个玩家席位、房间号、准备状态、房主状态、左上延迟。
- 屏蔽：玩家立绘、左上延迟之外的参考内容，以及画面下方靠右的“不搜寻队友｜终极模拟”。

每个可比区域计算：覆盖率、颜色平均绝对误差、像素差异比例和边缘位移估计。报告以“注意”列出超阈值区域，而不是令命令失败。输出 actual/reference/overlay/heatmap 四张图；热图只绘制未屏蔽区域。

## 素材溯源

报告从截图 manifest 与 `docs/references/ui/lobby/ASSET_MAP.md` 合并产生素材表。每项至少包含：

- 界面/截图状态与控件名称；
- Sprite 名称与 Resources 路径；
- 素材库相对来源路径；
- SHA-256；
- 在各截图中出现次数。

任一实际 Sprite 不在映射表中，或映射的来源/SHA 缺失，工具必须失败而不是生成可被误解为完整的素材报告。

## 输出

输出目录包含：

- `visual-diff-report.md`：摘要、区域指标、屏蔽说明、人工审查提示和素材表；
- `visual-diff-report.json`：同一结构化数据；
- 每个截图状态的 actual/reference/overlay/heatmap PNG；
- 复制的输入 manifest，仅作证据记录。

成功完成的视觉报告退出码为 `0`，即使存在“注意”差异。缺少/重复参考图、非法路径、输入图像尺寸不兼容、manifest 无效或素材溯源不完整时退出码非零，且输出目录不得被创建。

## 验证

1. PowerShell smoke：非法输出、缺失/重复图 9/10、未映射素材和尺寸不匹配均在写入前失败。
2. 固定 fixture：验证主页与房间各生成 overlay/heatmap、屏蔽区不会计入指标、发现项只预填房间号的截图记录存在。
3. 对真实 Windows Player capture 运行报告，检查五个状态均产出，并由人工审阅热图与素材表。
4. 相关 EditMode/PlayMode 和现有 capture/export 回归必须保持通过。

## 非目标

- 不要求原图与实际 UI 像素完全一致；
- 不修改大厅的业务行为、网络协议、战斗 HUD、场景、Prefab 或游戏贴图；
- 不替代 Windows–Android 同 Wi-Fi 实机验收。
