# 外部数据与文件链接安全规则设计

- 日期：2026-07-28
- 状态：已由项目负责人确认
- 范围：仓库根目录 `AGENTS.md`

## 目标

防止测试、临时目录清理或递归文件操作通过 junction、symbolic link、hard link 或其他 reparse point 意外修改项目外数据和用户提供的事实源。

## 已确认规则

在 `AGENTS.md` 的工具、Skill、权限与网络章节中新增独立的“5.8 外部数据与文件链接安全”：

1. 项目外数据和用户事实源默认只读；读取授权不等于写入授权。
2. 禁止在 Unity 生成目录、缓存、构建输出和测试临时目录创建指向外部数据的文件系统链接。
3. 外部数据测试只能复制最少必要文件到独立 fixture，不得链接或修改原始数据。
4. 递归删除、移动或清理前必须解析 reparse point；目标越界时停止。
5. 测试后以文件数量、必要文件集合和关键哈希等只读指标检查外部源完整性。
6. 外部数据受影响时必须立即停止，报告影响、因果链、恢复来源与所需批准，不能静默修复或继续使用受损数据。

## 验证

- `AGENTS.md` 只新增一个 `5.8` 章节，不改写其他规则。
- 新章节包含上述六条规则。
- `git diff --check -- AGENTS.md` 无格式错误。
- 本次只修改文档，不运行 Unity 编译、EditMode、PlayMode 或构建。
