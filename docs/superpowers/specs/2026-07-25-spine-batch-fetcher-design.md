# Spine 批量下载与资源命名设计

## 目标

提供一个位于 Unity 项目外的、只写入用户指定暂存目录的下载工具。工具从 PRTS 敌人一览收集候选敌人，排除所有攻击方式包含“远程”的敌人，逐页取得 Spine 模型和头像，并产出可人工导入 Unity 的完整资源目录。

Unity 项目随后统一采用由下载模型文件名得到的 ID 与英文名命名资源目录、头像和单位 JSON 文件。

本设计不把下载器、下载缓存、日志或临时资源放入 `G:\ARKnoNIGHTS_beta`，也不让下载器直接写入 `Assets/`。

## 术语与命名

- **模型基名**：详情页模型配置中的文件名，例如 `enemy_1000_gopro_3`。
- **下载 ID**：模型基名中的数字 ID，例如 `1000`。
- **英文单位名**：模型基名中 ID 之后、可选的末尾皮肤/变体段之前的英文段，例如 `gopro`。
- **规范单位键**：`<下载 ID>_<英文单位名>`，例如 `1000_gopro`。
- **皮肤/变体段**：模型基名末尾的数字段，例如 `_3`。该段保留在模型三个文件的基名中，但不进入规范单位键。

模型基名无法无歧义解析为上述组成部分时，工具必须将该页标为失败并保留证据；不得猜测目录名。

## 批处理下载器

### 输入与候选收集

下载器接收敌人一览 URL 和一个项目外的输出目录。它从敌人一览所使用的数据源收集详情页候选 URL，然后逐页读取：

1. 中文单位名；
2. 攻击方式；
3. 敌人模型配置中的资源前缀与模型基名；
4. 页面提供的单位头像资源。

攻击方式只要包含 `远程` 即排除，包含 `近战 远程` 的混合单位同样排除。`近战` 和 `不攻击` 不因攻击方式被排除。未能读出攻击方式的候选不得当作近战处理，而应记录为失败。

候选页必须存在可解析的模型配置才可继续。下载器不得通过浏览器自动点击“点此载入模型”；它应使用配置给出的资源 URL 下载模型文件。

### 完整单位产物

所有文件先下载到临时目录，只有模型和头像均校验成功后才原子性移动到：

```text
<输出目录>/staging/<下载 ID>_<英文单位名>/
  <模型基名>.skel.bytes
  <模型基名>.atlas.txt
  <模型基名>.png
  UIImage_<下载 ID>_<英文单位名>.png
  manifest.json
```

`.skel` 文件只改名为 `.skel.bytes`，不得尝试转成 JSON；`.atlas` 文件只改名为 `.atlas.txt`。模型 PNG 的像素内容和基名保持下载来源原样。

`manifest.json` 至少记录中文单位名、详情页 URL、模型前缀、模型基名、下载 ID、英文单位名、规范单位键、攻击方式、四个输出文件名和每个文件的 SHA-256。它用于人工导入前复核，不作为 Unity 的运行时数据。

规范单位键重复时，下载器不得覆盖任何既有暂存目录；两个候选都写入报告并标记为冲突。

### 头像与失败清单

头像必须是可解码 PNG，且原始尺寸严格为 `158 × 158`。通过校验后统一保存为：

```text
UIImage_<下载 ID>_<英文单位名>.png
```

头像缺失、无法下载、无法解码、不是 PNG 或尺寸不是 `158 × 158` 时，该单位不产生完整暂存目录。下载器将中文单位名按 UTF-8、一行一个、去重的形式写到：

```text
<输出目录>/invalid-portraits.zh-Hans.txt
```

批处理总报告 `report.json` 另外记录每个候选的状态、原因、来源 URL 和已发现的尺寸，以便定位页面或解析规则变化。因“远程”排除、无模型、重复规范键与头像不合格必须使用不同状态，不能混为下载成功。

### 网络和停止行为

工具只访问用户指定的 PRTS 页面及页面模型/头像配置所指向的资源地址；不上传项目内容，不使用登录信息，不启动服务。网络、页面结构、模型配置、文件下载或校验任一环节失败时，工具继续处理其他候选，但该候选必须在报告中失败。任何批次只要没有完整单位，命令应以非零退出码结束，不能把“0 个下载”报告为成功。

## Unity 资源迁移

下载器之外，项目内另行执行一次受版本控制的迁移。迁移仅处理人工审核后的完整暂存目录，并保留移动资源的原有 `.meta` 文件及 GUID。

目标布局为：

```text
Assets/Resources/Characters/<下载 ID>_<英文单位名>/
Assets/Resources/ProfilePicture/UIImage_<下载 ID>_<英文单位名>.png
Assets/GameData/Units/Json/<下载 ID>_<英文单位名>.json
```

下载 ID 成为该单位 JSON 的权威 `typeId`：导入或迁移时，JSON `typeId` 必须等于模型基名解析的下载 ID，否则显式失败，不静默改写。旧 `resourceKey` 可保留作兼容性或业务标识，但不得再决定任何实际 Resources 目录。

`profilePictureResourceName` 统一为 `UIImage_<下载 ID>_<英文单位名>`。目录生成器、旧 `UnitFactory`、Spine 探针和生成的 `Assets/Resources/BattleData/unit-catalog-v1.json` 都必须通过规范单位键解析模型目录与头像路径。现有直接断言旧 `Characters/<resourceKey>/...` 或旧 `UIImage_<resourceKey>` 的测试同步更新。

本次变更不改变 Spine 模型基名、动画名、Prefab、战斗规则或用户可见的 HUD 显示尺寸。HUD 继续可在 `180 × 180` 显示区域中等比显示原始 `158 × 158` 头像。

## 验证

下载器需要离线测试夹具覆盖：

1. 普通近战候选的完整输出和清单；
2. 纯远程与“近战 远程”候选均被排除；
3. 缺失攻击方式、模型配置或不可解析模型基名被拒绝；
4. `.skel -> .skel.bytes` 与 `.atlas -> .atlas.txt` 的文件名转换；
5. 158 × 158 PNG 通过；缺失、非 PNG、损坏、非 158 × 158 头像写入中文名失败清单；
6. 重复规范单位键不覆盖已有结果；
7. 空结果返回非零退出码，且报告可解析。

Unity 迁移完成后需要运行资源目录相关 EditMode/PlayMode 测试、重新生成并检查 `unit-catalog-v1.json`，再进行 Unity 编译。验证时检查实际资源加载、头像加载、Spine SkeletonData 加载和最终 diff；若 Unity、网络或解析工具不可用，必须标记为未验证。

## 非目标

- 不在 Unity Editor 内下载资源；
- 不自动把暂存目录写入 `Assets/`；
- 不下载或保留攻击方式包含“远程”的单位；
- 不把二进制 `.skel` 转换或伪装成 JSON；
- 不自动修复类型 ID、模型名、头像尺寸或页面解析歧义；
- 不重新分发下载资源或将其上传至外部服务。
