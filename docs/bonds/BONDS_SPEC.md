# 概述
局内的单位组合buff有两个维度，就像大部分自走棋棋子的游戏羁绊一样。
此游戏demo的羁绊含两个维度：种类和地区，每个可以由玩家购买的单位至少有其一。

种类有感染生物、萨卡兹、宿主、海怪、造物、化物、机械、坍缩体、无人机
地区region有莱塔尼亚、哥伦比亚columbia、萨米、维多利亚、卡西米尔、炎、东国、乌萨斯、叙拉古、谢拉格、萨尔贡、米诺斯、阿戈尔

以上不一定要全使用上
其中感染生物和无人机在地区的交叉度会很广。
