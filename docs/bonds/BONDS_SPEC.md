# BONDS 羁绊、单位与能力规范

局内的单位组合 buff 有两个维度，就像大部分自走棋棋子的游戏羁绊一样。
此游戏 demo 的羁绊含两个维度：种类和地区，每个可以由玩家购买的单位至少有其一。

当前使用的种类为感染生物、无人机、造物、机械、坍缩体和其他，共 `6` 种；萨卡兹、化物等备选种类暂未使用。
当前使用的地区为乌萨斯、莱塔尼亚、维多利亚、哥伦比亚 Columbia、萨尔贡、阿戈尔、叙拉古和整合运动，共 `8` 个；萨米、卡西米尔、炎、东国、谢拉格、米诺斯等备选地区暂未使用。

备选分类不一定要全部使用。其中感染生物和无人机在地区上的交叉度会很广。

本章只表达单位的种类归属，不作为地区章节的子分类。已有地区归属的单位在本章只列 `ID、名称、稀有度`，完整描述统一放在地区章节；尚无地区归属的单位在本章保留完整描述。
