## 全局技能动画规则

状态：已实现。

- 所有 Skill 动画按 `2×` 播放。
- v2 单位源保存动画 key、真实 Spine 名称和源时长；能力源保存技能使用的动画 key。
- `SkillAnimationCatalogGenerator` 将两份源交叉校验，生成独立的
  `skill-animation-catalog-v1`，不改变冻结的
  `unit-catalog-v1` 和 `ability-catalog-v1`。
- 源时长先按 `ceil(durationSeconds × 20)` 转为源 Tick，再按
  `(sourceTicks + 1) / 2` 计算 `2×` 后有效 Tick；奇数 Tick 向上取整，确保最后一个关键帧播放。
- Skill 事件把动画 key、源 Tick、有效 Tick传给 Track/Event Playback；Spine 使用固定 `2.0` 倍率。
- 已经开始的 Attack 优先完成。技能满 SP 后保持排队，在攻击动画结束后的下一 Tick 施放；Skill 占用期间不能开始下一次攻击或移动。
- 动作优先级：`Death > Attack > Skill > Move > Idle`。
