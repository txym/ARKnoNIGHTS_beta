### 生命阈值战斗修正

- 支持 `<=` 与 `<` 两种生命千分比阈值；比较使用整数交叉相乘，不引入浮点分歧。
- 支持“只要在阈值内就生效”和“首次越过阈值永久/限时生效”两种触发方式。
- 生效项可组合攻击倍率、防御倍率、阻挡数加算、攻速加算、移速倍率和强制不可阻挡；多个能力按稳定 ability ID 顺序应用。限时状态把触发 Tick 计为第一个有效 Tick，精确持续配置的 Tick 数。
