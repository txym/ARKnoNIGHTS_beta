## 全局技能动画规则

状态：已实现。

- 所有 Skill 动画按 `2×` 播放。
- v2 单位源保存动画 key、真实 Spine 名称和源时长；能力源保存技能使用的动画 key。
- `SkillAnimationCatalogGenerator` 将两份源交叉校验，生成独立的
  `skill-animation-catalog-v1`，不改变冻结的
  `unit-catalog-v1` 和 `ability-catalog-v1`。
- 源时长先按 `ceil(durationSeconds × 20)` 转为源 Tick，再按
  `(sourceTicks + 1) / 2` 计算 `2×` 后有效 Tick；奇数 Tick 向上取整，确保最后一个关键帧播放。
- Skill 事件把动画 key、源 Tick、有效 Tick传给 Track/Event Playback；Spine 使用固定 `2.0` 倍率。
- 已经开始的 Attack 优先完成。技能满 SP 后保持排队，在攻击动画结束后的下一 Tick 施放；Skill 占用期间不能开始下一次攻击或移动。
- 动作优先级：`Death > Attack > Skill > Move > Idle`。

## 已完成的通用能力框架

状态：Core 框架完成，等待真实单位目录接线。

### 被动战斗属性

- 阻挡数加算：覆盖 `1058 +2`、`1081 +2`、`1240 +1`。
- 法术抗性加算并在伤害计算时限制到 `0..100`：覆盖
  `1165/1166/1170 +70`、`1230 +60`。
- 攻速加算按
  `ceil(BaseIntervalTicks × 100 / (100 + AttackSpeedAdditive))`
  重算攻击间隔：覆盖 `10127 +100` 的底层语义。
- 物理/法术最终承伤千分比按稳定能力 ID 顺序相乘，真实伤害不受影响：覆盖
  `10127` 的物理/法术承伤 `50%`。

### 持续生命与寿命

- 每秒生命变化使用整数余量累计，不丢失不能整除 20 TPS 的部分。
- 正数在每 Tick 治疗并限制到 MaxHP；负数作为无来源真实生命流失，但不会播放 Hit。
- 覆盖 `1043 +160/s`、`1044/1061 +400/s`、
  `1062 -330/s`、`1089 -800/s` 的底层语义。
- 固定寿命在 `ActivationTick + LifetimeTicks` 精确归零并进入普通死亡清理：
  覆盖 `10002 6s=120 Tick` 与 `1146 30s=600 Tick` 的底层语义。
- 新增 `HealthChanged` Core 事件，Presentation Track 和事件播放均只更新血条，不伪造受击动画。

### 受击反伤

- 受敌方单位伤害时，对该次攻击来源造成固定无来源伤害；反伤不递归触发另一轮反伤。
- 反伤与原受击同 Tick 结算，随后统一处理死亡，因此致死一击仍完成已经由该次受击触发的反伤。
- 支持伤害类型、目标防御/法抗与目标承伤修正；覆盖
  `7002/10126` 的 `200` 无来源法术反伤底层语义。
- 查证依据：
  [PRTS 矿脉守卫](https://prts.wiki/w/%E7%9F%BF%E8%84%89%E5%AE%88%E5%8D%AB) 与
  [PRTS 异质源石虫](https://prts.wiki/w/%E5%BC%82%E8%B4%A8%E6%BA%90%E7%9F%B3%E8%99%AB)
  均明确描述“受到单位伤害时，对伤害来源造成 200 无来源法术伤害（无视其可选性）”。

聚焦验证：

- `BondsPassiveCombatModifierEditModeTests` 中本节对应的 `8` 项验证通过，覆盖三阻挡、法抗、攻速、物理/法术减伤且不影响真实伤害、每秒 `330` 的余量累计、每秒 `400` 治疗、120 Tick 寿命、致死受击反伤，以及 `HealthChanged` Track 采样。

### 生命阈值战斗修正

- 支持 `<=` 与 `<` 两种生命千分比阈值；比较使用整数交叉相乘，不引入浮点分歧。
- 支持“只要在阈值内就生效”和“首次越过阈值永久/限时生效”两种触发方式。
- 生效项可组合攻击倍率、防御倍率、阻挡数加算、攻速加算和移速倍率；多个能力按稳定 ability ID 顺序应用。
- 阈值状态在每 Tick 开始、直接伤害结算后和持续生命变化后刷新。同 Tick 同批伤害使用伤害前状态，下一阶段才切换阈值，避免单位 ID 顺序改变结算结果。
- 持续型阻挡加成因治疗失效时，会按 unit ID 稳定保留容量内关系并立即解除多余阻挡。
- 框架可表达 `1025` 的 `<=50%` 攻击倍率、`1232` 的 `<50%` 防御 `4×` 与阻挡 `+1`、`1264` 的首次受伤后 300 Tick 攻速/移速提升，以及 `1274` 的首次 `<50%` 后永久攻速/移速提升。
- `1025` 精英等级对应 `2×/2.8×` 的数据选择仍需下一代运行时目录接入；当前 Core 只负责执行已选定的倍率。
