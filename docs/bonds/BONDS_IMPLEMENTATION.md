# BONDS 单位能力实现台账

本文记录 `docs/bonds/BONDS_SPEC.md` 中单位战斗机制的实际实现状态。只有生产
数据流与必要验证均完成后才标记为“已实现”；只有 Core 能力但尚未接入真实
单位源时标记为“框架完成”。

当前任务读取的是主工作区在 2026-07-29 的最新 `BONDS_SPEC.md`。该文件包含
用户尚未提交的更新，本分支不复制或代为提交该用户修改。

## 暂不决断

- `10039` 只有“蓄力一段时间、范围物理伤害”的描述，当前缺少蓄力时间、
  伤害倍率与范围；查证前不实现数值效果。
- `1502` 的路径长度、重复触发后的 SP 恢复与冲家覆盖尚未在项目规范确认；
  先保留为后续核对项。
- 冲家事件如何改变单场胜负与何时结算玩家生命，当前 Core 尚无已确认闭环；
  特殊移动可先实现，但不会伪造胜方。
