# BONDS 单位能力实现台账

本文逐项记录 `docs/bonds/BONDS_SPEC.md` 中单位能力和特殊行动规则的实际实现状态。

## 笔记

- 所有数值都有两个乘区一个是加算乘区一个是乘算乘区
比如移速=基础移速*（1+加算和）*（最终乘算和）
- “能力描述”面向玩家，规范后写入 skill 相关 JSON；“能力详情”面向实现 Agent，记录精确数值、时序与接线状态。
- 目前所有伤害都打不到无人机，直接在攻击和伤害计算中完全移除无人机。
- 被召唤单位的精英化等级与召唤源相同

- 本文档内能力描述是更新skill相关Json的权威源。

## 统计口径

- 以一个拥有特殊能力或特殊行动规则的 TypeId 为一个条目；同一单位的一段复合能力仍算一个条目，子效果写入“能力详情”。
- “无特殊能力”的单位不进入本台账，也不进入完成率分母。
- 全局技能动画、索敌、阻挡、冲门等公共机制单独记录，不计作单位能力。
- 精英化字段只比较能力本身的数值或效果，不把生命、攻击、防御等单位基础属性成长算作能力数值变化。
- 只有 Core 计算、生产能力源或单位数据接线、运行时消费链和必要定向验证都完成，才标记为“已实现”。

状态定义：

- **已实现**：玩家可见能力已进入生产数据流，并完成必要定向验证。
- **部分完成**：已有一部分生产行为或 Core 语义，但仍缺少能力子效果、表现、生产接线或运行时基础设施。
- **框架完成**：Core 已能表达并验证完整的 BONDS 数值语义，但真实单位的 v2 `innateAbilityIds` 尚未接线。
- **未实现**：尚无能够承载该能力主要语义的 Core 与生产实现。

## 已完成的公共机制

### 技能动画

- 所有 Skill 动画固定按 `2×` 播放。
- 源时长先按 `ceil(durationSeconds × 20)` 转为源 Tick，再以 `(sourceTicks + 1) / 2` 计算有效 Tick；奇数源 Tick 向上取整，保证动画完整播放。
- 已经开始的攻击优先完成。技能满 SP 后排队，在攻击结束后的下一 Tick 施放，不删除待结算攻击。
- Skill 占用期间不能开始下一次攻击或移动；动作优先级为 `Death > Attack > Skill > Move > Idle`。

### 索敌、阻挡与特殊行动

- `AttackMethod.None` 不索敌、不产生 Attack。
- `Untargetable` 与历史能力 ID `UntargetableByMelee` 都从全部敌方索敌及伤害候选中排除；`1017/1042/1146/1355` 的全部 v2 变体已接入且不会被近战、远程、范围或反伤命中。
- `blockCapacity=0` 不建立阻挡关系。
- 可移动单位没有合法目标时直接前往敌方门；静止单位 `actionMethod=4` 不移动。
- 单位进入以门中心为中心、边长 `0.8m` 的闭区间正方形后立即退出战斗并结算 `lifeDeduct`。
- `1146` 使用“从己方门到部署位置”的定向移动；到达前不启用光环。
- 定时召唤、攻击/受击触发召唤、生命阈值召唤和死亡后继均继承召唤源的精英化等级。
