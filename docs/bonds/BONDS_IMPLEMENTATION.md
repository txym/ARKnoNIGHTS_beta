状态：已实现。

- 所有 Skill 动画按 `2×` 播放。
- v2 单位源保存动画 key、真实 Spine 名称和源时长；能力源保存技能使用的动画 key。
- `SkillAnimationCatalogGenerator` 将两份源交叉校验，生成独立的
  `skill-animation-catalog-v1`，不改变冻结的
  `unit-catalog-v1` 和 `ability-catalog-v1`。
- 源时长先按 `ceil(durationSeconds × 20)` 转为源 Tick，再按
  `(sourceTicks + 1) / 2` 计算 `2×` 后有效 Tick；奇数 Tick 向上取整，确保最后一个关键帧播放。

### 持续生命与寿命

- 每秒生命变化使用整数余量累计，不丢失不能整除 20 TPS 的部分。
- 正数在每 Tick 治疗并限制到 MaxHP；负数作为无来源真实生命流失，但不会播放 Hit。
- 覆盖 `1043 +160/s`、`1044/1061 +400/s`、
  `1062 -330/s`、`1089 -800/s` 的底层语义。
- 固定寿命在 `ActivationTick + LifetimeTicks` 精确归零并进入普通死亡清理：
  覆盖 `10002 6s=120 Tick` 与 `1146 30s=600 Tick` 的底层语义。
- 新增 `HealthChanged` Core 事件，Presentation Track 和事件播放均只更新血条，不伪造受击动画。

### 受击反伤

- 受敌方单位伤害时，对该次攻击来源造成固定无来源伤害；反伤不递归触发另一轮反伤。
- 反伤与原受击同 Tick 结算，随后统一处理死亡，因此致死一击仍完成已经由该次受击触发的反伤。
- 支持伤害类型、目标防御/法抗与目标承伤修正；覆盖
  `7002/10126` 的 `200` 无来源法术反伤底层语义。
- 查证依据：
  [PRTS 矿脉守卫](https://prts.wiki/w/%E7%9F%BF%E8%84%89%E5%AE%88%E5%8D%AB) 与
  [PRTS 异质源石虫](https://prts.wiki/w/%E5%BC%82%E8%B4%A8%E6%BA%90%E7%9F%B3%E8%99%AB)

- 只剩待爆炸效果的阵营仍保持战斗待定，爆炸结算后才进入终局判断；范围伤害读取目标当 Tick 防御、法抗和承伤修正，但不作为普通攻击触发受击反伤或闪避。事件保留已经死亡的 owner unit ID 以供审计与 Presentation 定位，不把它恢复成存活伤害来源。

### 攻击范围伤害

- 攻击开始时已封存的攻击序号决定本次是否转为范围攻击；支持从指定序号开始一次性或按固定间隔重复。范围攻击沿用已封存的本次攻击力和破防倍率，再应用独立的伤害类型与攻击力千分比。
- 圆形模式以主目标在伤害 Tick 的位置为中心，按整数厘米平方距离选取所有敌方存活实体；十字模式把主目标与候选当前位置映射至最近的 9×8 战场格（距离、X、Y 稳定决胜），覆盖中心格及上下左右一格。

### 命中后持续生命流失

- 只有普通攻击实际造成正伤害时才施加效果；闪避或其他零伤害结果不施加。范围攻击的每个实际命中目标分别进入同一流程。
- Runtime 按 ability ID 保存目标身上的持续伤害状态；同名效果再次命中时更新每秒伤害并把失效 Tick 重置为“当前伤害 Tick + 持续 Tick”，不新增叠加层。不同 ability ID 可并存。
- 持续伤害与被动生命变化共用20 TPS整数余量结算，并输出 `HealthChanged`/无来源真实生命流失；它不播放普通 Hit，也不递归触发受击反伤或闪避。施加所在伤害 Tick 即计入第一 Tick，失效 Tick 在生命周期阶段前移除，因此100 Tick持续时间精确结算100个 Tick。

### 未阻挡攻击蓄力

- 每层是最终攻击固定加算，位于阈值、解放状态和光环攻击倍率之后。Attack 开始时把含当前层数的攻击力封存；到该次普通攻击的伤害/动画结束 Tick 清空全部层数，即使原目标已死亡而取消出伤也会清空。

### 攻击/受击计数触发召唤

- 受击触发按每个正伤害普通攻击 Hit 递增；同 Tick 多来源按目标 ID、攻击者 ID 的稳定顺序计数。目标在同批总伤害后仍存活时，第10、20……次受击可触发；致死批次不从已经死亡的 owner 生成新单位。
